個人情報の取り扱い

MedQuickにおける個人情報および医療情報の取り扱いについてご案内します。

1. 取り扱う情報

MedQuick（以下「本アプリ」といいます。）では、 利用者が自ら入力・登録した以下の情報を取り扱います。

  • 氏名
  • 生年月日
  • 血液型
  • 服用している薬に関する情報
  • 既往症・持病等に関する情報
  • 備考として登録した情報
  • 緊急連絡先に関する情報
  • かかりつけ医療機関に関する情報
  • その他、利用者が本アプリに登録した情報
これらには、健康状態や病歴等に関する情報が含まれる場合があります。

2. 利用目的

本アプリで登録された情報は、以下の目的で利用します。

  1. 利用者本人が自身の医療情報を確認するため
  2. 緊急時に、利用者が指定した相手へ医療情報を共有するため
  3. QRコードを利用した医療情報の共有・受け取りを行うため
  4. 本アプリの機能を提供・維持するため
  5. 本アプリに関するお問い合わせへの対応を行うため

上記の目的以外で、登録された医療情報を利用することはありません。

3. 情報の保存について

本アプリに登録された医療情報は、原則として利用者の端末内に保存されます。

本アプリでは、利用者が登録した医療情報を提供者が運営する サーバーへ自動的に送信して保存する仕組みを採用していません。

4. QRコードによる情報共有について

本アプリでは、登録された医療情報をQRコードとして出力し、 別の端末で読み取って共有することができます。

QRコードによる共有は利用者自身の操作によって行われます。

利用者がQRコードを第三者に提示した場合、 そのQRコードを読み取ることができる第三者に情報が提供される可能性があります。

QRコードを提示・共有する際は、共有する相手や周囲の状況を十分に確認してください。

5. QRコードの読み取りについて

本アプリのAndroid版では、QRコードの読み取りに Google Code Scannerを利用しています。

Google Code Scannerを利用して読み取ったQRコードの内容は、 本アプリが受け取り、医療情報の復号・登録等の処理に使用します。

6. 第三者への提供

本アプリの提供者は、利用者が登録した医療情報を、 利用者の意図しない第三者へ販売、貸与または提供することはありません。

ただし、法令に基づく場合、生命・身体または財産の保護のために必要がある場合など、 法令上認められる場合を除きます。

また、利用者自身がQRコード等を利用して第三者へ情報を共有した場合は、 利用者自身による情報提供となります。

7. 情報の安全管理

本アプリでは、利用者の医療情報を保護するため、 端末内に保存する情報の暗号化など、適切な安全管理措置を講じるよう努めます。

ただし、利用者自身がQRコードを第三者へ提示した場合など、 利用者自身の操作によって情報が第三者へ渡った場合については、 本アプリ提供者がその後の第三者による情報の利用を管理することはできません。

8. 利用者による情報の管理

利用者は、本アプリの機能を利用して、 登録した医療情報を編集または削除することができます。

また、受け取った医療情報についても、 本アプリの削除機能を利用して削除することができます。
